# Libraries By Language
These libraries are ones that I understand, am proficient with, generally trust to be free of malware, and thus favor during development.

They are organized by language, and list their purpose.

It is deliberate that they do not list details or installation instructions, as the specifics of these libraries can change over time. In order to use one, you should begin by looking it up.

# Python (mostly via PyPI)
- Data Processing: numpy, pandas, polars
- Machine Learning: sklearn, tensorflow
- Visual CLI Elements: rich, tqdm
- CLI tools generally: typer
- Interactive TUI tools: curses
- APIs: gRPC
- Web APIs: FastAPI
- Vision: cv2
