# standards
This repository defines technical standards which I use across my projects.

It mostly exists to help AI tools standardize their usage when building, so that they settle on known best practices, and, in particular, tools and patterns that I personally understand.

## Resources List
- project_structure.md: The basic setup of a project.
- libraries.md: Libraries that I am familiar with and favor using, organized by language.
- stack.md: Tools, mostly for the CLI.
